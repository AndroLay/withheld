## Evidence classes

- `VERIFIED_SOURCE`: checked against the committed source or configuration.
- `VERIFIED_RUN`: a command completed with exit code zero.
- `VERIFIED_ARTIFACT`: a report or screenshot generated by a verified run.
- `HISTORICAL_LOCAL`: an older local observation retained only for context.
- `SELF_REPORTED`: supplied by a person or document and not independently replayed.
- `UNKNOWN`: not established by the available evidence.
- `ENVIRONMENT_BLOCKED`: not run because the required environment or access was unavailable.
