What this page cannot know four limits, stated once

Whether the marks are right. It checks that a rubric line id exists and that nobody wrote to a stale revision. Whether the line was truly expressed is a judgement, and it stays yours.

Whether an answer is a person’s own work. Nothing here detects that.

Whether a held answer deserves the hold. The band is a rule, not an opinion: it holds every answer close to the line, including the ones you would have released.

Whether the student ever sees it. Release ends at the click. What a school’s own system does after that is outside this page.
